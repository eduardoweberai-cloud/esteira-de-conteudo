# Logos

SVGs do [Simple Icons](https://simpleicons.org) (CC0 1.0). As marcas pertencem aos donos; use só para se referir ao produto de verdade, sem sugerir parceria ou endosso.

Para pôr outro logo: baixe o SVG em simpleicons.org e salve aqui como `<nome>.svg` (o mesmo nome que vai no reel.json, ex.: `{ "tipo": "logo", "logo": "github" }`).
