# Efeitos sonoros (opcional)

O repositório não traz efeito sonoro nenhum: os bancos de som gratuitos deixam usar o som no seu vídeo, mas não deixam redistribuir o arquivo num repositório. Sem esta pasta, o reel sai sem efeitos e nada quebra.

Para ter o "poc" quando algo aparece, o "whoosh" nas trocas de cena e o resto, baixe sons curtos (Mixkit, Pixabay ou outro banco que permita uso em vídeo) e salve aqui com estes nomes, em `.mp3`. O kit toca só os que encontrar e mede a duração de cada um sozinho.

| Arquivo | Quando toca |
|---|---|
| `pop.mp3` | tudo que aparece na tela (quadro, cabeçalho, card, número, selo) |
| `pop-2.mp3`, `pop-3.mp3`, `pop-4.mp3` | entram no rodízio com o `pop` pra não cansar o ouvido |
| `whoosh-short.mp3`, `whoosh.mp3`, `whoosh-cinematic.mp3` | troca de cena e entrada de palavra grande |
| `impact-curto.mp3` | abertura do vídeo, explosão, tremor, clarão, selo (até 0,5 s; impacto longo vira ronco) |
| `glitch-curto.mp3` | batida `glitch` (até 0,6 s; glitch longo vira ruído branco) |
| `sparkle.mp3` | brilho, confete, chuva |
| `moedas.mp3` | chuva de moedas (sem ele, toca o `sparkle`) |
| `typing.mp3` | terminal e chat digitando, contador |
| `key-press.mp3` | cada letra da palavra no "comenta" |
| `notification.mp3` | a DM chegando |
| `click-soft.mp3` | botão "Seguir" virando "Seguindo" |
| `click.mp3` | risco |
| `ping.mp3` | linha OK no terminal, contador chegando |
| `error.mp3` | batida `xis` |

Os arquivos desta pasta ficam fora do git (`.gitignore`) para ninguém publicar som de banco sem querer.
